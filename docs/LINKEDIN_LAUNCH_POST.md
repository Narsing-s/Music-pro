# LinkedIn launch post — Narsing Music

🎵 **Building Narsing Music: my Android music player project**

I’ve been working on **Narsing Music**, a native Android music player focused on a clean, modern listening experience and reliable local playback.

✨ **What’s included**
- Browse local tracks, albums, artists, genres, folders, recent plays, and favorites
- Search and sort your music, create playlists, and manage the playback queue
- A vinyl-inspired identity with a monochrome UI and red accents
- Background playback with Android media notification and lock-screen controls
- Local-first design — no account required and no music uploads
- GitHub Actions workflow to build a debug APK

I’m continuing to refine the interface while keeping existing playback and library behavior intact. The project is built with **Kotlin, Jetpack Compose, and AndroidX Media3**.

🔗 Source code: https://github.com/Narsing-s/Music-pro  
📱 Latest CI build: https://github.com/Narsing-s/Music-pro/actions/workflows/android-apk.yml

Feedback and suggestions are welcome — especially around usability, background playback, and the Android music-listening experience.
