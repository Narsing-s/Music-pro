# Security Policy

## Supported versions

Security reports are currently accepted for the latest code on the default branch. Narsing Music is an actively developed project and does not yet publish a formal long-term support schedule.

## Reporting a vulnerability

Please do not publish credentials, private files, or a weaponizable vulnerability in a public issue.

If GitHub's **Report a vulnerability** option is enabled for this repository, use it to submit a private report. Otherwise, contact the repository maintainer through their GitHub profile and ask for a private reporting channel before sharing sensitive details.

Please include the affected version or commit, Android version, impact, and concise reproduction steps. Do not include real passwords, tokens, or private music files.

## App privacy and permissions

The app is designed around local device music. When reporting a suspected privacy issue, explain what information appears to leave the device and how you observed it. Do not send private listening history or personal media as evidence.
